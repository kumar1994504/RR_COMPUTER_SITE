### முறை 1: 1-Click தொடக்கம் (மிகவும் எளிதானது)
ஃபோல்டரில் உள்ள **`start-server.bat`** ஃபைலை இரட்டைச் சொடுக்கு (Double-click) செய்யவும்:
- தானாக லோக்கல் சர்வர் தொடங்கப்பட்டு, உங்கள் பிரவுசரில் **`http://localhost:8081`** திறந்துவிடும்!

### முறை 2: Node.js அல்லது Terminal
```bash
# சர்வர் தொடங்க
node server.js
```
அல்லது:
```bash
npm start
```

### 1. 93+ சேவைகள் & 9 துறைவாரியான பகுப்பு (9 Sectors Categorization)
முகப்புப் பக்கத்தில் (`index.html`) மற்றும் சேவைகள் பக்கத்தில் (`services.html`) அனைத்து சேவைகளும் சரியான 9 பிரிவுகளாகப் பிரிக்கப்பட்டு மல்டி-கேட்டகரி பில்டருடன் இணைக்கப்பட்டுள்ளன:

1. **வருவாய்த் துறை (Revenue)**: சாதி, வருமானம், இருப்பிடம், முதல் பட்டதாரி, வாரிசு சான்றிதழ், இதர வருவாய் சேவைகள்.
2. **உணவு & வழங்கல் (Food & Ration)**: புதிய ஸ்மார்ட் ரேஷன் கார்டு, பெயர் சேர்த்தல்/நீக்கம், முகவரி மாற்றம், குடும்பத் தலைவர் மாற்றம் (TNPDS).
3. **அடையாள அட்டை (Identity Cards)**: ஆதார் (UIDAI), பான் கார்டு (NSDL/UTI), வாக்காளர் அடையாள அட்டை (ECI), பாஸ்போர்ட் சேவா, ஆயுஷ்மான் பாரத் (ABHA).
4. **நில ஆவணங்கள் (Land Records)**: பட்டா/சிட்டா பார்வை & பதிவிறக்கம், 'அ' பதிவேடு, FMB வரைபடம், வில்லங்கச் சான்றிதழ் (EC), வழிகாட்டி மதிப்பு.
5. **நலவாரியம் & மகளிர் (Welfare & Women)**: தமிழ்நாடு கட்டுமான நலவாரியம் (TNDWWB), கலைஞர் மகளிர் உரிமைத் திட்டம், PM-KISAN, முதியோர்/விதவை ஓய்வூதியம்.
6. **மின்சாரம் & நகராட்சி (Utility & Municipal)**: TANGEDCO மின் கட்டணம் செலுத்துதல், புதிய மின் இணைப்பு, சொத்துவரி, குடிநீர் கட்டணம், பிறப்பு/இறப்பு சான்றிதழ்.
7. **போக்குவரத்து (Transport & Parivahan)**: ஓட்டுநர் உரிமம் (LLR / Driving Licence), RC புக், Fastag ரீசார்ஜ், இ-சலான் கட்டணம்.
8. **கல்வி & தேர்வு (Education & Exams)**: TNEA பொறியியல் சேர்க்கை, TNGASA கலை/அறிவியல், NEET, சட்டப் படிப்பு, TNPSC, காவலர் தேர்வு, ஆசிரியர் தகுதித் தேர்வு (TRB/TET), அஞ்சல் துறை (GDS).
9. **வணிகம் & MSME (Business & Trade)**: MSME உத்யாம் பதிவு, GST பதிவு, FSSAI உணவுப் பாதுகாப்பு உரிமம், தொழிலாளர் உரிமம்.

### 3. நேரடி நகரும் அறிவிப்புப் பட்டை (Live Scrolling Marquee Ticker)

அனைத்து பக்கங்களிலும் தலைப்பின் கீழ் சுழலும் **Live Marquee Ribbon** அமைக்கப்பட்டுள்ளது:
- **`data/updates.json`** கோப்பிலிருந்து நிகழ்நேர அறிவிப்புகளை தானாக வாசித்து ஒளிரும் சிவப்பு பேட்ஜுடன் (`[முக்கிய அறிவிப்பு]`, `[தேர்வு பதிவு]`) காண்பிக்கும்.
- மவுஸ் பாயிண்ட்டை வைத்தால் ஸ்க்ரோலிங் நின்றுவிடும் (**Hover Pause**).
- தமிழ் மற்றும் ஆங்கில மொழி மாற்றத்திற்கு ஏற்ப அறிவிப்பு தானாகவே மொழிபெயர்க்கப்படும்.

#### அறிவிப்புகளை மாற்ற 2 எளிய வழிகள்:
1. **Windows Desktop App**: **`manage_updates.bat`** ஃபைலை Double Click செய்தால் ஒரு நவீன விண்டோ திறக்கும். அதில் புதிய அறிவிப்புகளை டைப் செய்து 1-Click மூலம் சேமிக்கலாம்.
2. **Browser Web Manager**: பிரவுசரில் **[admin-updates.html](file:///admin-updates.html)** திறந்து நேரடி முன்னோட்டத்தைப் பார்த்துக்கொண்டே அறிவிப்புகளை மாற்றலாம்.

### 6. தமிழ் எழுத்துக்கள் ஒன்றுடன் ஒன்று மோதுவது சரிசெய்யப்பட்டது (Tamil Typography Fix)

Windows Command Prompt மற்றும் பிரவுசரில் தமிழ் எழுத்துக்கள் (ி, ீ, ு, ூ, ெ, ே, ை, ்) ஒன்றன் மேல் ஒன்று ஓவர்லேப் ஆகாமல் இருக்க:
- `site.css` மற்றும் `matisha-theme.css`-ல் உள்ள negative letter-spacing நீக்கப்பட்டு, தமிழ் எழுத்துருக்களுக்கு Windows அதிகாரப்பூர்வ **`Nirmala UI`** முதன்மையாக வைக்கப்பட்டுள்ளது:
  ```css
  [lang="ta"], :lang(ta), .ta, html[data-lang="ta"] * {
    font-family: 'Nirmala UI', 'Mukta Malar', 'Noto Sans Tamil', sans-serif !important;
    letter-spacing: normal !important;
    word-spacing: normal !important;
    text-rendering: optimizeLegibility !important;
  }
  ```
- Command Prompt-ல் எழுத்துக்கள் உடைவதைத் தவிர்க்க, அனைத்து மேலாண்மை மென்பொருட்களும் Windows Desktop GUI-ஆக மாற்றப்பட்டுள்ளன.

## 🌐 இணையத்தில் லைவ் (Hosting) செய்வது எப்படி?

### Cloudflare Pages (பரிந்துரைக்கப்படுகிறது - 100% வாழ்நாள் இலவசம்):
1. இந்த ஃபோல்டரை GitHub-ல் உங்கள் கணக்கில் பதிவேற்றுங்கள் (`git push`).
2. [dash.cloudflare.com](https://dash.cloudflare.com) சென்று **Pages → Create project → Connect to Git** தேர்வு செய்யவும்.
3. **Build settings**: Build command தேவையில்லை (Empty), Output directory: `/` (Root).
4. **Deploy** அழுத்தவும்; சில நொடிகளில் உங்கள் தளத்திற்கு இலவச SSL உடன் கூடிய `.pages.dev` முகவரி கிடைத்துவிடும்.
5. பின்னர் [Settings → Custom Domains] சென்று உங்கள் சொந்த டொமைனை (எ.கா: `localhost:8081` அல்லது `rktec.in`) இலவசமாக இணைத்துக் கொள்ளலாம்!
